## Spectroform
Spectroform is a blender extension which generates meshes from a sound wave from audio file. It takes the waves from the audio file and the python modules render them as a sine and cos wave in multiple directions that generates a continuous mesh.

# What it does?
Basically, it caputes audio from any audio files like MP3, WAV, AAC etc. then analyse its soundwaves then using python modules it converts them into 3D waves in blender, as the sound continues the waves changes according to amplitude and wavelength. It uses sine and cos waves to generate these waves
